MilkDrop Visualizer

Play any music file — .mp3, .m4a, FLAC, AAC, WAV… — and the MilkDrop window opens by itself at full resolution. It closes when you close it, and it won't reopen for that same track. The next track brings it back (Settings toggle: auto-launch).

MilkDrop Presets

MilkDrop Originals (551) — the presets released with MilkDrop itself.
Geiss' Favorites (1,352) — Ryan Geiss's own favorite presets from geisswerks.com, with 1,249 already in the catalog or MilkDrop Originals and 101 newly converted.
All (1,927) — every unique preset that also appears in Originals or Geiss' Favorites is listed a single time here — and Favorites.

The window also loads the MilkDrop Texture Pack (all 67 original textures) plus the extra textures that shipped in Geiss's Favorites, so presets that sample a named texture (worms, sunrise, clouds, manyfish) render with the real image instead of a fallback.

Random Order toggle: while it is blue, Next picks presets at random (shuffle, no repeats). Switch it off and Next steps through the collection in alphabetical order. Presets auto-cycle every 30s by default — pick the interval (15–90s) from the small menu attached to it.

How it hears the music

IINA's plugin API has no tap on the player's audio output, so the plugin reads the playing file itself and streams its bytes to the window, which decodes them with Web Audio and plays the decoded buffer in sync with IINA — the visuals react to your actual song. (The file-system permission exists only for this read.) Fallbacks in the picker footer: Mic / system capture and an Ambient beat. DRM files (Apple Music downloads) can't be decoded — use Mic mode for those. The current frame rate is shown at the bottom left of the window.

If something looks stuck

Click the window once (macOS mutes webview audio analysis until the window gets a click), then check Plugin ▸ MilkDrop Visualizer ▸ Diagnostics and IINA's Log Viewer, filter “MilkDrop”.
